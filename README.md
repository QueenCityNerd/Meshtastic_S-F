This is a simple room server modeled on Meshcore but for Meshtastic devices that lack on board memory space such as my Heltec V3. When coupled with a Raspberry Pi this python script gives the node store and forward when it is direct messaged. 

All DM's to the node will be saved. And to check messages send "history", "read", or "board" and it will send back the last 5 messages by default. You can increase this if necessary.
